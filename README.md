# LAQTA Hackathon 2026: The First Ahlan
**Hosted by:** QIC (Qatar Insurance Company)

**Participant:** Nausheen Khan

**Challenge:** Build a full AI marketing campaign (Part A) and an AI-personalized HTML landing page prototype (Part B) in one day.

## 🚀 The Campaign: "The First Ahlan"
**Product:** QIC Visitor Insurance

**Slogan:** *Cut the red tape. Keep the welcome.*

**The Insight:** Mandatory visitor insurance feels like frustrating red tape. We reframed it as the first act of Qatari hospitality.

**The Visual Style:** 3D faceless Pixar/claymation aesthetic using QIC's brand colors (Arabian Night, Maroon, Pearl).

## 📁 What's in this repo?
*   `Part-A-Ahlan.pdf`: The full 8-slide campaign strategy, social rollout, and budget.
*   `Part-A_Hero-Film.mp4`: The 20-25 second AI-generated hero video.
*   `Part-b-Ahlan.pdf`: The 5-slide AI deck explaining the dynamic landing page.
*   `index.html`: A fully functional HTML/CSS/JavaScript landing page prototype. It features a 3-question quiz that dynamically rewrites the page's headline based on the user's answers.
*   `qic-logo.png` & `hero-image.png`: The assets used in the HTML file.

## 🛠️ How to run the HTML prototype
1. Download the entire folder.
2. Double-click `index.html` to open it in your browser.
3. Answer the 3 questions in the quiz and click "Personalize" to see the AI logic in action.
4. Watch the Hero video
